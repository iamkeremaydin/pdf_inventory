First public release of PDF Master Suite — Inventory.

- Scan folders for PDFs: page counts, sizes, modified dates, and problem reports for corrupted or encrypted files.
- Find duplicates by size, partial hash and full SHA-256.
- Filter, sort and export the visible rows to CSV.
- Clean download-site tags out of PDF filenames, with a preview, collision skipping and an undo report.
- Portable: everything the app writes goes into `pdf_inventory_data` next to the program.
- English and Turkish interface.

**Downloads** (no Python needed):

| System | File |
| --- | --- |
| Windows | `PDF-Master-Suite-windows-x64.exe` |
| macOS (Apple silicon) | `PDF-Master-Suite-macos-arm64.zip` |
| Linux (x86-64) | `PDF-Master-Suite-linux-x86_64.tar.gz` |
